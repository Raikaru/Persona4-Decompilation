## Reproduction and mechanism

The surviving source archive supplied rank55's complete Wave hunk and rank56's
three-local declaration ordering. That authentic baseline freshly measured
2652 bytes, 269 fully resolved differing words, 255 masked words and 106 stock
alignment edits. The historically reported 59-edit source was lost and was not
available for reproduction; it is not used as an evidence baseline here.

The measured sequence kept genuine operations and their actual dependencies:

1. Group the real unsigned trail element offset before the array addition.
2. Materialize the address of the existing complete snapshot object at both
   actual snapshot assignments; no extra object, escape or dummy access.
3. Give the final-amplitude variation and preroll elapsed fraction their own
   completed scalar lifetimes, keeping the existing load/call order.
4. Load negative one at its actual angle-sign use. Reverse complete equivalent
   expiration/local-space/angle-mode arms to recover original block layout.
5. Give the real zero/one/half/two values and two distinct gravity products
   truthful scalar names. The compiled preroll ACC/product/subtraction sequence
   matches retail exactly; no extra multiply, truncation or forced round-trip.
6. Compute the used primary index from the **live** emitter base at each trail
   phase, rather than substituting the captured loop index. This closes two
   operand-order words while preserving callback-sensitive reloads.
7. Keep the byte-valued initial-preroll phase distinct from the wider loop flag:
   `u8 initialPreroll = 1; preroll = initialPreroll;`. The value is initialized,
   actually consumed and exactly promoted to 1. Matched sibling 0048a980 uses the
   same narrow-to-wide source pattern (`u8 third=2; selected=third;`) and its
   entire 584-byte captured body is retail-identical. This grounded producer
   lifetime closes the final `addiu`/`daddiu` materialization difference.

The retained scoped propagation/loop-invariant settings are recognized MWCC
