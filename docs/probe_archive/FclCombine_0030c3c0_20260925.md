# Fcl combine state machine 0030c3c0

`func_0030c3c0` in `src/Event/Fcl/y_fclCombine.c` is now C and verifies as
MATCH. `verify.py` reports a 12584-byte object in the 12592-byte window with
0 differing words and 347 relocations. The file now has 30 MATCH functions.

## Starting point

The guarded m2c draft measured 2257 fnalign edits. A body rewritten from the
retail assembly measured 2229 edits and came up 123 instructions short.

The beq chain tests the case labels in reverse source order. Read backwards,
it gives this case order:

A0, A1, A2, A3, A4, CE, A8, A9, AA, AB, B2, B3, B5, B6, B4, B7, AC, AD, AF,
B0, B1, AE, B8, B9, BA, BB, BC, BD, BE, BF (falls into C0), C0, C1

## Levers, in the order they paid off

- **`u8 *p` for the stores, with `*(s8 *)(p + X)` for the signed fields.**
  Retail stores the state bytes 0xA1 to 0xD2 as positive immediates.
- **`#pragma opt_loop_invariants on`** (push/pop). The slot-membership
  scan appears about 20 times. Retail loads its count and kind once, before
  the loop (2086 -> 1143).
- **The membership scan is a `static inline` helper.** It returns 1 from
  inside the loop and 0 after it, which gives retail's per-use result
  register and its `== 1` test.
- **The id from `func_002e48a0(...)[1]` is held unmasked.** It is passed
  straight to `func_00105f50(u32)`, and narrowed to `(u16)` only for the
  `iGpffffb440 + id * 0x11` name offset (the `andi` retail has there).
- **The 0x2D8/0xB0/0xE timers are stored first and then re-read.** Retail
  stores the halfword before it sign-extends the value.
- **Each loop has its own counter** (387 -> 213). The i-loops of A8, A9, AA,
  B2, AC, AF, B1 and AE each get a fresh variable. So do the six-kind loops.
- **`func_003042f0` inlined in AC.** It is written as a `static inline`
  copy, with the kind read into a local before the roll call. This restored
  the two inlined switches, 62 instructions each.
- **Struct slots for the B2 tables.** `FclCombineSlot {s8 kind; s8 weight;
  s16 item;}` gives the index-first `addu`.
- **The six-kind scans after A1 are hand-written scans.** They cover A2, CE,
  AB, B5, B4 and B7. Their `q`/`k`/`found` temporaries are declared before
  the outer counter. With the inline helper, the outer counter always took
  `$t2` and the inner one `$t1`; retail has the reverse. Declaration order,
  names, loop forms, helper signatures and block scopes did not change that.
  A1 keeps the helper, and there the helper's allocation is the retail one.
  The swap accounted for 62 register-only lines.
- **`opt_propagation off` plus `slot = (s8 *)(p + 0x2DA) + i`** in AC. This
  gives retail's `addu $v0, $v0, $s0` before the 0x1F store (the last edit).
