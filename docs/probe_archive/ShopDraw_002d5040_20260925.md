# Shop stat panel 002d5040

`func_002d5040` now matches: 4,424 native bytes in the 4,432-byte retail
window (1,108 words; the last two are zero alignment). The previous floor
was 95 words (`ShopDraw_002d5040_body_20260925.c`), instruction-count exact
with every difference one `$s0`/`$s1` swap: retail keeps `work` in `$s1`
and the short-lived values in `$s0`.

## What closed it

The stat numbers were drawn with `shopDrawStat(value_expr, x_expr, y)`, an
inlined helper. Writing each draw as

    x = <x base>;
    value = <getter>((s32)id) & 0xFFFF;
    shopDrawStat(value, x, y);

with `u32 value; f32 x;` function locals (declared after `work`; their
position among the locals is inert) gives retail's colouring and keeps
every instruction. Only `x` named leaves the swap (95); only `value` named
gives the registers but hoists the x base after the value call (132).

## How the lever was found

Stripping statements out of the draft and watching which register `work`
got (`lw $sN, 0x38($a0)`) localised it: removing the stat draws, or keeping
only two of the eight, puts `work` back in `$s1`; removing the labels, the
top item draw, the deltas or the final `if`s does not. A third
stat-shaped call flips it whenever its value stays live across the
struct-returning `func_002b2970`/`func_002b2a60` calls, whether the value
is an inline parameter or a block local; the same value live across plain
calls (`func_002b3170` three times) does not flip it.

Writing the draws without the helper (statements straight into
`func_002cacd0`) also fixes the registers, but costs 38 words: the stat
`func_002b2970` temporaries are then laid out in call order among the
item-draw temporaries. With the helper, b210 places inline-body
temporaries after the main-body temporaries and after the label helper's
parameter copies (retail: item draws 0x108..0xC0, label copies 0xB8/0xB0,
stat temporaries 0xA8..0x70), so the helper has to stay.
