# Row frame: exact `func_00317900`

`func_00317900` in `src/Event/Fcl/y_fclCombineDraw.c` compiles to its full
retail window (3896 bytes of code plus 8 bytes of padding in the 3904-byte
window), with every relocation resolved.

The old guarded body with named packets was at 769 words. The rewrite
started from point-by-value calls with `(u8 *, FclVec2, FclVec2, s64, s32,
s32, s64)` parameters: both points are homed with `sd`, and `arg4` and
`arg5` are passed raw. Everything else came from `fnalign` blocks, closed one
at a time (normalised for stack offsets).

1. **Anchor copy.** `FclVec2 pos = func_002b2970(arg1.x, arg1.y);` as a
   declaration initializer gives retail's temp (`0x210`) plus float-pair copy
   into `pos` (`0x218`). Each form was measured:
   - Plain assignment returns straight into `pos`. That takes its address,
     so every `6.0f + pos.x` is reloaded instead of held in `$f24/$f25`.
   - A block `r` followed by `pos = r` adds an extra `ld/sd`.
   - The comma form, the inline helper and `*&r` were all worse.
2. **`s16 sprite`**, plus local externs
   `func_002b6c30(s16, FclVec2, f32, s32)` and
   `func_002b69f0(.., s32)`. The last one keeps `arg4` raw (`move $t1,$s3`).
3. **`orderUp = order + 1`** as a named local (`$s0`), used by two
   `func_002b6c30` calls.
4. **`scale = iGpffff8360`**: one `lwc1` for both stores.
5. **Fade orders.** `fadeA/B/C = (s16)arg4 + k` go through a local
   `func_002b6a70(s16, u8, u8, s32, s32, s16)`. Each call then converts the
   order again (with an explicit `(s16)` the conversion is CSE'd into the
   variable).
6. **Table index.** It is written `((s16 *)(work + 0xC8))[*(s8 *)(work +
   0xB4) * 5]` for retail's `addu idx*10, work` operand order.
7. **Frame id.** `frameId = frame = (s8)arg3 + 0x20D;` goes before
   `depthUp = (s16)arg5 + 1;`, which puts the `(s16)` conversion into `$a0`
   ahead of the depth. The following forms all left it after the `cvt.s.w`:
   - a separate `frame` statement,
   - a `(s16)` cast,
   - an assignment inside the argument list,
   - `s32` or `s64` prototypes.
8. **Else-branch frame id.** The else-branch `func_002b69f0` spells the
   frame id as `(s8)arg3 + 0x20D` rather than `frame`. Using `frame` there
   makes b210 reuse the `+0xF2` temp in `$fp` instead of retail's
   `addiu $s1,$s1,0xf2`.

`tools/permute.py` found nothing from the 9-word state (1748 compiles). The
last two levers were found by hand.
