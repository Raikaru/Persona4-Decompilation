## Recovery and ABI

The callback transforms both the triangle normal and its vertices through the
atomic's frame matrix, normalizes the transformed normal, rejects excluded
planes, and collects the nearest contact for each normal. Both comparison and
record updates use the transformed normal. The previous guarded C incorrectly
stored the original triangle normal. Existing edge contacts store the closest
edge point; a newly appended edge contact stores the plane projection, matching
retail's distinct behavior.

`FldFrameCollisionCollector` recovers all 64-entry parallel arrays: points at
`0x000`, normals at `0x300`, distances at `0x600`, corrections at `0x700`, and
flags at `0xa00`. Mode, count and hit count are at `0xb00`, `0xb04`, and `0xb08`;
direction begins at `0xb0c`, the real 28-byte RenderWare intersection at `0xb18`,
and the atomic pointer at `0xb34`. No alignment filler or synthetic state was
added. `func_0016a0c0` now passes this typed collector and intersection directly.

The local plane helper snapshots the transformed normal before scanning. The
existing world-triangle helper remains unchanged, preserving `00169320`.
The interior distance/flag path calls `fldFrameCollectorOffset`, which adds the
byte offset and `uintptr_t` collector address entirely as integers before the
final pointer conversion. No arithmetic starts from an integer-cast nonobject
pointer. The appended flag's actual value is retained before its address lookup.
Separate counters describe the independent vertex-transform and edge traversals.

Each transformed vertex has a union containing a real `RwV3d` and a real
`f32 components[3]` array. The point-in-triangle helper receives an actual
`f32 *vertexPointers[3]` array whose elements point to those component arrays.
There is no incompatible pointer-array cast or scalar-member array indexing for
the vertices. The edge helper receives the same vertices through their vector
view. The correction preserves the entire completed native object byte for byte.

The PS2 RenderWare geometry callback contract is
`RpCollisionTriangle *(RpIntersection *, RpCollisionTriangle *, f32, void *)`.
`00169a30`, `0016b350`, and `0016b770` now share that exact contract. Every return
path returns the supplied triangle pointer; the distance argument remains in the
ABI even when unused. Registrations use typed function pointers directly.
`00394e70` has the corresponding atomic/intersection/callback/data signature and
atomic-pointer return. Retail geometry dispatch at `00394048` and `00394c24`
supplies three integer arguments and the distance in `$f12`, then tests `$v0`.
The SDK source contract is also retained in `include/rw/sky2/rpcollis.h`.

`003e9700` receives a frame pointer, consistent with its current provider and
the retail frame load at `003e9710`; all uses in this owner now pass pointers.
`003e40b0` returns the vector length in `$f0`, and its declarations now retain
that float return. Vector/point transforms `003e4360` and `003e42e0` return their
destination pointers, as their complete retail wrappers show. No provider source
