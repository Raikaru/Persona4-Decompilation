## Recovered source

The fresh guarded baseline emitted 3,072 bytes with 412 aligned instruction
edits. The old note's larger frame was stale: both current baseline and retail
use a `0xD0` frame. The important missing objects were the complete RGBA
snapshot at `sp+0xCC..0xCF` and the shared position at `sp+0xC0/0xC4`.

The graph's two branches populate one color and join at one sprite call.
The previous draft duplicated that call and kept only independent RGB values.
The option row's palette copy is a complete four-byte transport; its blue and
green channels, opacity, Y coordinate and resource handles have distinct
callback-crossing lifetimes. The same position record is also used for the
option text, reset button, description and help footer.

The allocation and initializer establish a `0x4B0` work object with:

- Seven halfword timers at `0x3A`, six option values at `0x48`, and six
  previous option values at `0x60`
- Eighteen 48-byte animation records at `0x78`; their position is at `+0x10`,
  opacity at `+0x1A`, and interpolation frame bounds at `+0x28/+0x2C`
- Eleven ten-byte graph entries at `0x3D8`
- Eleven sprite handles at `0x448`, followed by the help texture at `0x474`

Option rows use the signed work-relative byte walk. The button group uses a
size-based animation lookup and holds its two field addresses across callbacks,
then reloads the live coordinates for the second draw. These are distinct array
accesses, not an invented wide local or a register reservation. The graph's
height and fill values likewise stay live during its sprite callbacks.

The timer's completed path precedes the callback/increment path. Its halfword
address is retained across calls; the increment reads the post-callback value.
The pending option is flushed after the traversal. Background position, base
fade and selected option remain entry snapshots.

The unselected special row packs a gray shade through a byte-alpha color helper;
other text paths combine the retained opacity with their packed RGB constants.
Both unselected paths display the same gray while retaining their separate
source roles. No artificial data, padding, uninitialized input, ordinary-memory
volatile or instruction assembly is used.

The existing local backdrop declaration is corrected to the canonical
`(Vec2f, s32, s32, f32)` contract from `nLine.c`; this changes no bytes. The
`0.6f` graph coefficient is the same immutable float pool entry at `0x00761260`
recovered in the persona renderer. Its four emitted bytes are `9A 99 19 3F`.
