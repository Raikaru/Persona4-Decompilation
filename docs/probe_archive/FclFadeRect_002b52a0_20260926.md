# func_002b52a0 (code1_002b.c) — MATCH (2026-09-26, campaign g1 round 4)

Size 2488B plus zero padding, in a 2496B window. The old draft stood at
548 words. This was a fresh rewrite from the retail listing on a typed
FclFadeRect record (vertices at 0x10, colour bytes at 0x110, geometry and
fade fields at 0x128..0x188).

Levers:
- The dispatch is a switch written `case 2`, `case 0/1`, `case 3`, which b210
  emits as the retail 3/1/0/2 chain. Case 2 falls through into the shared
  vertex build, and the shared path ends in `break` so that it reaches the
  single trailing `return 0`.
- `if (wait == 0) { ... } else { wait = func_002b2d00(...); return 0; }`
  puts the wait path after the fade body, as retail does.
- The mode chain is an if/else chain with separate, identical bodies for
  modes 3 and 4.
- `(f32)byte` on the u8 colour fields gives the unsigned-conversion
  sequence by itself, with no casts or hand expansion. The u8 alpha store
  from the float result gives the 2^31 float-to-unsigned path.
- The alpha copy loops use their own index `j`, separate from the vertex
  loop's `i`. Sharing one index costs 59 words.
- `extern f32 D_008872F8[4]` is sized, so the far depth is re-read on each
  iteration. Unsized, it gets hoisted. `#pragma opt_loop_invariants on`
  hoists only its %hi. Loading it into a local `farZ` before
  `farZ - work->depth` gives retail's load order (3 words otherwise).
