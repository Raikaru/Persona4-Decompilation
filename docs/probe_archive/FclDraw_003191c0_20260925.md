## The scale / y FP colouring

The scale global `iGpffff8504` (gp -0x7AFC) is loaded once in each branch of
the first block, and `$f21` is reused for every later `func_002b6af0`. That
makes it a local `sc` assigned in both first-block branches. `extern const`
also reuses it, but the load is then absolute (`lui`/`lwc1`), not
gp-relative. It also breaks two matched functions.

With `sc` as the only float local, b210 gave the compiler's `arg1.y` CSE
temporary `$f21` and `sc` `$f22`, which is swapped from retail (26 words). Two
float locals are coloured last-declared-lowest. So `y` is declared before
`sc`, and it is used only where retail reads `$f22`: both first-block point
constructors, the 83e0 rows, the 0x39/0x250 else rows and the 34b820 point.
Everything else still spells `arg1.y`, and the compiler reloads those itself.
In the then-branch, `y = arg1.y` has to sit inside the first
`func_002b2970` argument so that the load follows the 2.0f materialisation.
As a separate statement it costs 11 words.
