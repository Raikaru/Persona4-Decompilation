# Detail-row digits: exact `func_0031c2b0` and `func_0031cce0`

Both functions in `src/Event/Fcl/y_fclCombineDraw.c` compile to their full
retail windows (2608 and 2384 bytes) with every relocation resolved.

## The lever: `func_002b2970` returns its point by value

Every earlier draft (566 and 507 differing words, then 35-60 after the
changes below) treated `func_002b2970(u8 *out, f32 x, f32 y)` as a void
writer into a named stack packet. The `$a0 = sp+N` argument is the EE hidden
result pointer of an aggregate return, exactly like `func_002b2a60` and its
`FclDrawColor`. With a block-scope

```c
extern FclVec2 func_002b2970(f32, f32);
```

each point is built inside the call that consumes it:

```c
func_002b69f0(0x7C, func_002b2970(arg2.x, arg2.y - 2.0f),
              func_002b2970(arg3.x, arg3.y - 2.0f), 0, 0xA, 0);
```

Because both endpoints are now one expression, MWCC evaluates the pure
destination-Y arithmetic (and shares its constant) before the first
constructor call. That was the whole FPR-rotation / "early lwc1 0x74"
residual, which named float locals, CSE-shaped rewrites and 160+ declaration
permutations could not reproduce. The file-scope `func_002b2970` prototype is
left untouched for its matched callers.

## Other facts both functions needed

- Signature `(u8 *, s16, FclVec2, FclVec2)`. Retail homes both points with
  `sd` and takes a local `FclVec2 pos = arg2` copy (0x138/0x148). Only the
  first 69f0 pair reads the `arg2` home directly.
- Colours are `FclByte4` values from `func_002b2a60`, stored by struct
  assignment to `func_002b6150(id) + 0x85`. That gives retail's
  `lbu x4 / sb x4` batch.
- `w` is an `s16` (`lh`). `b` is an `s16` loaded from a `u8`. The digit uses
  `func_00109280((u16)w) & 0xFF` with the file-scope prototype.
- The `b >= 10` split is plain `if/else` with `%10` and `/10`, plus `+0x46`.
  `func_0031c2b0` also has its trailing 0x74 sprite.

## Also measured on `func_00324680` (not matched, 15 words)

The same struct-return form plus these levers brings `func_00324680` to 15
differing words:

- `FclVec2 *v = (FclVec2 *)D_...` for the lui/addiu table base.
- `s32` parameter types in local externs for `func_003191c0` and
  `func_0031ac10`. These force the loads of the immediate `lhu`/`lbu`/`lb`
  argument, and make those values temporaries in `$s6`/`$s7`.
- A local s16 `func_002b6c30` extern to pass the resource raw.
- Block-scope `off`/`on` locals across the first loop, and inline
  recomputation after it.

The remaining 15 words are all in the second loop: retail keeps the counter
in `$s0` and its `(s16)` copy in `$s3`, and b210 swaps them. Declaration
order, loop form, counter width, reusing `i`/`arg1` and copies into named
locals were all measured without closing it. The draft is
`FclDraw_00324680_body.c`.
