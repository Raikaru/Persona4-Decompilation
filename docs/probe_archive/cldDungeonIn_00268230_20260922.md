## The entry address and the four vector copies

The old 12-word masked residual was a source-address lifetime difference.
Retail computes the stack entry-array element into `$s4` before the first
of four 16-byte copies. That call copies the initial vector. After it
returns, retail computes the current-vector address into `$s1` and passes
the same address to the current and previous vector copies. The fourth
copy supplies the target vector. Older owner comments incorrectly called
this a destination calculation across the third call.

The loop index is an unsigned integer bounded by 19. Forming
`copyEntry = &entries[(s32)i]` after the scalar node stores keeps the second
entry base across the initial copy. The conversion is exact for every
iteration. Repeated `copyEntry->current` expressions then rematerialize
the member offset, emitting 1,592 bytes. Expressing each source as
`(u8 *)copyEntry + offsetof(DungeonInEntry, current)` makes the derived
address a shared expression and restores the exact retail instruction
sequence. The entry is 76 bytes and this actual member begins at byte 28;
both source ranges remain within that entry. No added effects, volatile
objects, artificial instructions, or compiler-option changes are involved.
