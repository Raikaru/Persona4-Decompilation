## Global shape differences (fix these before any regional work)

- **Frame:** retail uses `-0x790` and saves `$fp` plus `$s0`-`$s7`. The draft uses
  `-0x450` and does not save `$fp`, so it is one callee-saved register and
  0x340 bytes of locals short.
- **Stack census:** retail touches almost every slot exactly once.
  - About 160 eight-byte slots from `0x150` to `0x650` are `Vec2f` temporaries.
    Each is filled by `func_002b2970(&v, x, y)` (lwc1/lwc1 or lui+mtc1 immediates)
    and then passed by value with `ld`.
  - Byte slots from `0x6A8` to `0x78F` are `RGBA` temporaries. Each is filled by
    `func_002b2a60(&c, r, g, b, a)` (58 calls) and copied bytewise to
    `func_002e04e0(...)+0x79..0x7C`. The draft spells this with
    `fclWriteColorBytes`.
  - Every missing call site therefore also means a missing unique slot.
- **Entry registers:** retail has `arg0 -> $s4`, `work = arg0->0x38 -> $s1` and
  `$s3 = 0` before the dispatch. The draft has `arg0 -> $s1`, `work -> $s0`, and no
  zero-initialised local. m2c did not recover the local behind `$s3`.
- **Returns:** `-1` from the 0x37 exit path, `0` at the shared default
  `.L002CA728`. States 11/25/26 share the default block. The dispatch and both
  jump tables are already documented in the source comment and are correct in
  the draft.
