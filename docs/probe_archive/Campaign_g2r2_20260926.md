## Cross-cutting levers found this round

- **gp-relative float "globals" are compiler literals.** fGp/iGp/D_0076xxxx
  names for constants such as 1/255 (-0x7FBC), pi (-0x7F7C), 0.01, 0.3, 0.6,
  pi/2, the sine-series coefficients at -0x7FB0..-0x7F9C, 562.5 etc. are merged
  `.sdata` literals. Writing the literal (`1.0f / 255.0f`) lets the unit's normal
  CSE reproduce retail's per-block reloads; forcing reloads of an extern with
  `opt_common_subs off` is what produced the old `mtc1 $zero` re-prime floors.
  `tools/build.py` links the literal fine (shared literal atoms). Candidates:
  00471370 and 00475cd0 (mdlManager, CSE-off guards with sine coefficients),
  0046b380 (sdkSpr), 00250ad0, 001ee610, 00225ec0.
- **Loop-invariant hoisting explains sq/lq spills.** Retail `sq`/`lq` stack
  slots holding sign-extended s16 values are hoisted loop-invariant temporaries
  (`opt_loop_invariants on`) spilled as whole registers, not a compiler floor.
- **Static inline helpers returning 1/0** reproduce retail's `x = 1; b` /
  fall-through `x = 0` joins for list-membership scans (as in 002848c0).
- **Unprototyped float callees** go through `fptodp`; make sure the callee
  prototype is in scope when the definition is still INCLUDE_ASM.
