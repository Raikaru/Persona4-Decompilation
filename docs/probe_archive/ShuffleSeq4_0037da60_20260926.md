## Shape

- 22-state `switch` on the state word with the same fall-through chains as
  the twins (1->2, 4->6->5, 7->8->9->10->11, 14->...->19 returning 1).
- Releasing a held card (`func_00375ec0`, the 0.7071 axis / unit rotation
  pair, `func_00376170`, clearing the held bit and slot) is a static inline
  helper; retail expands it three times with its own stack pair each time.
  Drawing a random free card (`func_00378530` count, rejection loop on the
  held-bit mask) is a second inline whose `arg0 + 0x1F1D0` base is hoisted
  out of the caller's loop.
- `opt_loop_invariants on` is required (674 words without it).
- Case 5 uses its own loop counter; sharing `j` with the later loops swaps
  $s2/$s3.
- Case 16 addresses the card state as `(u8 *)(idx * 0xE8) + (u32)arg0`, the
  file family's existing idiom, which gives retail's offset-first `addu`.

## Callee contract (all callers still MATCH)

The card-animation setters take their frame range as u16 all the way down:
`func_00372870`, `func_00372c30`, `func_003723a0` (btlShuffleCalc.c),
`func_003760f0`, `func_00376070` (now also takes the float speed it passes
through), `func_00376170` (pointer arguments typed `f32 *`),
`func_00375b40` (btlShuffleDraw.c), `func_00379090` (btlShuffleSeq.c) and
`func_0037d630` (this file). Retail masks the frame numbers at each call

unmasked; `func_003723a0` converts its u16 arguments to float directly, which
replaced the hand-written unsigned conversion without changing its bytes.

arrays the release helper uses. H011 in the seven touched files: 125 -> 103.
