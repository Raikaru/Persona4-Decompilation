is zeroed and filled by `func_0010cad0`.

## Levers

- Three `static inline` helpers: `yListExcluded` (the body of
  `func_002e6230`, which is now written as a call to it), `yListContains`
  (the `func_002e48a0` scan) and `yListEntry` (the entry-address switch). The
  1/0 returns give retail's `$v1` joins, and the two uses of `yListEntry`
  give the two jump tables. A real call to `func_002e6230` is not inlined.
- The persona table is indexed as a byte array
  (`iGpffffb3d4[i * 0xE + 2]`), which loads the base before scaling `i`, as
  retail does. Pointer arithmetic scales `i` first (4 words).
- The limit is an `s32` holding the `s16` result, so the `lq` spill is used
  without re-extending it.
- No separate `u16 id` local. Passing `i` straight to the `u16` parameters
  lets the compiler's own `(u16)i` temporary take `$s0`, which leaves retail's
  `$s0`..`$s3` order (24 words to 0). Adding a `u16` local of either width,
  in any declaration position, keeps a 4-register rotation.
- `opt_loop_invariants on` (push/pop) is needed: 29 words without it. The
  other list builders in this file use it too.
