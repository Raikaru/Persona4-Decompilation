# Fcl combine state machine 002f9d90

`func_002f9d90` in `src/Event/Fcl/y_fclCombine.c` is now C and verifies as
MATCH: 8460 executable bytes in an 8464-byte window, 0 differing words, and
298 resolved relocations. The file went from 26 to 27 MATCH. No other function
changed status.

## Starting point

The guarded m2c draft measured 1101 fnalign edits against this tree, and 2172
object instructions against retail's 2116. Tuning it was not worth it. A new
body written from the retail assembly measured 265 edits on the first compile,
and each lever below brought it down to 0.

## Levers, in the order they paid off

- **`func_00275820` prototype.** frFontEx defines it as
  `(f32 x, f32 y, f32 scale, int color, s8 chr, int id, const char *str, ...)`.
  With the floats first, the row y `(f32)(i * 23 + 0x80)` is computed before
  the `func_002e48a0` string call and `mov.s $f13, $f20` lands where retail
  has it. The old draft's float-last prototype moved that copy after `$t3`.
- **One local per value.** Retail keeps the in-loop alpha in `$s5`, the
  post-loop alpha in `$s1`, and the roster alpha in `$s3`. A single shared
  `alpha`/`color` merged these live ranges and pushed `arg0` from `$s2` to
  `$s4`. Separate locals took the count from 97 to 29 edits. A separate `s16 j`
  for the 0x68 loop took it from 29 to 10.
- **Int alpha with the `(u8)` cast, passed to an int-parameter `002b2a30`.**
  The alpha is `andi`'d twice and then passed unmasked to both colour
  builders. Its defining source masks every channel itself (`arg & 0xFF`).
  With a `u8` local, the merged if/else definition gets re-masked for the
  `s32` parameter of `002b2a60`. With an `s32` local and a `u8` parameter, the
  mask moves to `002b2a30`. The only 0-edit combination is `s32` locals with
  `(s32 x4)` for `002b2a30`, declared locally with a note.
- **`> 5` / `> 0xD` in the state range checks.** Retail's `slti $at` /
  `bnez $at` form comes from `x > 5`. `x >= 6` gives `slti $v1` / `bnez $v1`.
- **`FclVec2 *base = (FclVec2 *)D_00640E70`.** This keeps the address in
  `$s1` across the three `func_002b2970` calls. Indexing `f32 D[]` directly
  re-materialised `lui` each time.
- **Chained stores and copies:**
  - `a[0x6E] = b[0x6E] = 0xFF` gives the `andi $s1, $s1, 0xff` between the two
    0x27D/0x270 stores.
  - The 0xCC/0x66 pairs are a `u8 shade` local stored twice. That reproduces
    the `move $s4, $s7`.
- **Ternary for the 0x68 footer alpha.** Retail ends each branch with one
  `andi` and does a second `andi` at the join.
- **Smaller details:**
  - `iGpffffb3d4[idx * 14 + 2]` gives `addu idx, base`.
  - `((u8 *)p)[1] = 0xC5` keeps `addiu 0xC5`.
  - The state pointer is `s8 *`, so `-1` stores share one register.
  - `FclDrawColor` locals give the 4x `lbu`/`sb` slot copy.
  - `FclPackedPosition` locals give the aligned `ld`.
  - `*(FclVec2 *)(ps + 0x38)` gives the `ldl`/`ldr` pair.

## Tooling note

A variant loop that strips the other `INCLUDE_ASM` rows from the TU before
compiling brought one measurement down from about 30 s to 2 s. The object for
the target function is unchanged, which makes hill-climbing practical. A
declaration-order hill climb (150 to 200 swaps) found nothing here: every
register fix above came from source shape, not declaration order.
