## Shape

- **Display half** (retail up to 0x002CF144):
  - hide the three E40 bars;
  - `func_002e2a00(list)` set means go to the `busy = 0` exit;
  - an empty list (`func_002e26f0(list) <= D_00748908[sel]`) gets the grey
    bars;
  - otherwise it draws the scroll thumb, the price box (`fC20`, or
    `qty * (func_00106a90((s16)item) / 5)`), the cursor boxes, and the row
    loop over `start .. start + (s8)func_002b2cb0(0, count, 5, 0, 1)`. Each
    row is either the three-slot header row or an item row: icon by
    `func_00106880` flags, name, and two `func_002cacd0` numbers.
- **Input half**:
  - the guard is `arg1 != 2` plus eight idle checks;
  - then the D_008C0276/027A/024E button chain: up and down (with and without
    repeat), page, jump, the tab switches `& 8` / `& 4` (slides reset,
    `func_002d4760`/`func_002d7c10`, `func_002e3560`), confirm `0x40`,
    `0x80`, and cancel `0x20` with the long close-animation block.
  - The cancel block falls straight into `clear: busy = 0`. Retail has
    `.L002D1550` there, directly before the epilogue.

## What moved the count (fnalign edits)

- 2019 to 1633: hand-rewrote the display half from the listing.
- 1141: a file-local `ShopBuyWork` overlay:
  - `void *obj[0xB8]` from 0xC38, so `obj[i + 0x3A]` and `obj[f7 + 0x3B]`
    are the D20/D24 tables;
  - `list[3]` at 0xF18;
  - `ShopBuySlide slides[2][5]` at 0xFA0, indexed up to `[2]` like retail;
  - `select`/`scrollSave` s8[3] at 0x1168/0x116B, and `f1170`.

  Member indexing is what gives retail's `idx*4 + work` operand order at
  `list[sel]`.
- 1095: call-first compares, `func_002e26f0(list) > D_00748908[sel]`, and
  `(s16)func_002e26f0` as the fourth argument of `func_002b2d00`.
- 1004: block-scoped slide-reset counters, a plain `switch` on the new tab,
  and the `f1170` shapes (see below).
- 940: gp floats:
  - `iGpffff8504` is the 0.0f argument of the nine `func_002e0700` calls;
  - `fGpffff8520/8524/8528` are the second argument of the three
    `func_002e0940` calls;
  - `func_002e04e0` is called three times per EC4..CC0 slide (first result
    kept for the `ldl/ldr` u64 argument).
- 820: `work`, `item`, `top`, `i` declared first among the scalars. Their
  order among themselves does not matter; declaring them before the colour
  and Vec2f locals does.
- **194: one block-scoped s16 counter per loop.** There are eight loops. A
  shared `i` pinned every loop to one register. This is the same lever as
  func_002d1590.
- 199 to 193:
  - cancel block falls into an in-block `clear:` label, so there are no
    extra `b` around the epilogue;
  - `work->cursor = func_002b2cb0(..); if (work->cursor == 0)`, a store
    then a forwarded, sign-extended test, as retail does;
  - a `b = (Vec2f *)D_0063F888` base in the row code.
- **154: no `act = work->sel` local anywhere.** Written as `work->sel`, mwcc
  keeps the loaded sel in a saved register across the calls (retail `lb $19`
  once). It recomputes `sel*4 + work` at each `list[sel]`. An explicit s8
  `act` instead made mwcc CSE the whole `&list[act]` address into `$s5`/`$s2`,
  which retail never does. It also moved `item` to retail's `$s1`.
- 140: the `f1170` test reads `work->f1170` inline in the compare, with no
  temp. Retail loads sel first, then keeps `f1170` in `$s2`.

## Residual (140 edits, 33 of them not register renames)

- **`$s2`/`$s3` swap between `top` and the display temporaries: about 100
  edits.** Retail colours `top` (the `func_002e2700` result, live to the
  input half) `$s2`, and every display temporary `$s3`: the prologue loop
  counter, the kept sel, `price` (mflo), `iconColor`, and the header-loop
  counter. The draft gives temporaries `$s2` and `top` `$s3`. None of these
  changed it:
  - declaration order of `work/item/top/i`, any of four permutations;
  - `register`;
  - `top = (s16)func_002e2700(..)`;
  - `s32 top` (worse, 187);
  - `i = 0` before the calls;
  - block-scoping all display locals;
  - merging `act`/`i`.
- **0x3A loop (about 14).** Retail re-extends the counter into a copy for
  the arithmetic, recomputes `&obj[i + 0x3A]` after the `if (i > 0)` colour
  block, and passes the raw counter to `func_002e0660` (s64 parameter)
  without `dsll32/dsra32`. The draft extends it.
- **0x43 loop second counter (4).** Retail carries a dead second s16
  induction variable (`$s2` from 0, incremented each pass). A
  `for (i = 0x43, k = 0; ..; i++, k++)` with `k` unused is eliminated by
  mwcc, and a 0-based `i + 0x43` index is not strength-reduced into it.
- Scheduling:
  - `fC20` is loaded later in the first `func_002cacd0` (2);
  - `move $a0, $s4` sits after the sel sign-extension around
    `func_002d4760` (2 x 2);
  - one tail `nop`.
