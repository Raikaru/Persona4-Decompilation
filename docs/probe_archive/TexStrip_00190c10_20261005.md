## Source changes that closed the difference

State and loop variables have separate, meaningful lifetimes. The manifest
length is consumed directly by the write call; it no longer shares an
integer temporary with the allocated copy buffer. The descriptor belongs
to the file-processing state, and each open result is tested at assignment.
These are ordinary C lifetimes and expressions, with no dummy uses.

The resource-table byte offset is retained across property callbacks while
the owning resource pointer is reloaded from the task. Caching the header
or entry across those calls omitted retail loads. Resource and output-list
bounds use the unsigned comparisons present in retail.

The function's existing loop-invariant setting is now contained by
`#pragma push` / `#pragma pop`. Standard string declarations use their real
return and pointer types. Five pathname views in `func_00191850` were made
explicit `char *` conversions to accommodate those declarations; its
instructions and size remain unchanged.
