## Levers confirmed this round

- Local declaration order sets stack order in reverse: the first declared
  local gets the highest address.
- A two-element array (`seg[2]`, `seg[0] = seg[1]`) copies with lwc1/swc1
  pairs. Two plain 8-byte struct locals copy with ld/sd.
- A copy that retail makes through a pointer variable set before a call,
  e.g. `goal = base + 0x90C; ... else { node = goal; while ... }`, keeps
  retail's empty `b cond` trampoline.
- Loads of the same pointer through different types (`*(s32 *)arg0` against
  `*(u8 **)arg0`) are not CSE'd. This reproduced one of retail's reloads in
  004b8350.
