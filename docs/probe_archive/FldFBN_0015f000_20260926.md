# func_0015f000 (k_fldFBN.c) - MATCH, fresh rewrite (group 0, round 4)

Window 0x600 (1528B code + 8B pad). Frees the FBN part work table after
loading every part model into its scene resource.

Relocations: gp iGpffffb2a0/a4/a8, D_00764364; rodata axis {0,1,0} at
D_005F10E8 (a local `SVec3 axis = { 0.0f, 1.0f, 0.0f }` in the loop body, copied
each iteration: ld + lwc1); D_005F1068 file string; D_008873F4/jtbl_008873EC
heap alloc/free pointers.

Levers that closed it (from a 92-edit first draft to 0):
- Rid declared before the resource pointer (s2/s1 order).
- `u8 mode = 3;` declared before the aggregates, so its li precedes the
  axis copy.
- Entry addresses as byte offsets (`FBN_ENTRY(i)`) give retail's
  `addu base, off` order. The array-index form gives `addu off, base`. In the
  first loop only the field_10 argument is written `iGpffffb2a0[n].field_10`.
  Using the macro there puts the offset sll before the gp load.
- `u32` stride (fbn+0xC) and heap size (res+0x28C): the loads are scheduled
  after the first argument, as retail does.
- Data selection written as `else if (arg1 != NULL) fbn = arg1; else return 1;`.
  The coalesced copy leaves retail's beqz/b pair.
- A mode-0 `mtx = rec + 0x20` local keeps rec+0x20 in s1. `size = &rec[0xC]`
  reproduces the s7 address that is held across the two calls.
- An if/else-if chain on kind, not a switch.
- Retail passes angles.y (sp+0xC4) to func_0047a1a0 before the loop body writes it.
