## Contract and shape (all measured)

- The signature is `(u8 *, s32 mode, FclVec2 a, FclVec2 b, s32 show, s32 back)`.
  y_fclCombine.c's local extern `(u8 *, s32, s64, s64, s32, s32)` is
  ABI-identical.
- `u8 *t = ...` and `FclVec2 pos = func_002b2970(57.0f, 72.0f)` are
  declaration initializers, in that order. That gives the `t` load before the
  call and the 0x308 temporary copied to 0x318.
- `+ 600.0f` is written `+ span` with `f32 span = 600.0f`. b210 moves a
  literal constant to the left operand, but it keeps a propagated local on the
  right, and retail has `add.s f12, x, 600`. This took opcode distance from 78
  to 7.
- The row snapshots `*(FclVec2 *)(func_002b6150(id) + 0x38)` are `cur0` (0x310)
  plus an array `FclVec2 row[11]` at 0xE0..0x137. Separate locals are placed
  in use order before the temporaries, and neither declaration order nor block
  scope moves them. The array lands exactly on retail's slots (485 to 239).
- The slot index is `(u8 **)(t + 0x258) + (s8)(u32)arg1 * 2`. The `(u32)`
  stops CSE with the mode test, and retail recomputes it from `$s1`. The
  pointer-plus-index spelling gives retail's `addu v0, idx, t` order.
- `order` is split into `order0`/`order1`, one for each half (239 to 172).
  Splitting `id` per block made no difference.

## The residual

Retail colours `arg5 s0, arg1 s1, order s2, id/slot s3, arg4 s4, mode s5,
h s6, t s7`. The draft gets `id0-5 s0, arg4 s1, mode s2, order0 s3, arg5 s4,
arg1 s5`, and the second half already has `id s3`.

None of these moved the colouring:

- Declaration order: 150 plus 120 random permutations, 0 change.
- Parameter copies into locals: all 26 combinations identical.
- Explicit `mode`/`show` locals.
- `s8` parameter types.
- Slot as an expression instead of a local.
- Merging or splitting `h`, `slot` and `id` in any grouping.

Ternary and if/else forms of the id/order selects change the opcodes (5755+).
A 900 s `tools/permute.py` run only reached 161, through `#pragma tailcall off`
and operand swaps. The colouring follows some usage-based priority that
source shape has not reached yet.
