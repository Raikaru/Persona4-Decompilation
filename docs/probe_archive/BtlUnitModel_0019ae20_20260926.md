  `RtQuatUnitConvertToMatrixMacro` (rw `rtquat.h`) written out. First the nine
  products (`square`, `cross`, `wimag`), then `1 - 2 * (...)` and
  `2 * (...)`. Retail computes all nine products up front, and the msub/mul
  operand order follows the macro. The draft's hand-expanded
  `(a*b + c*d) * 2.0f` form interleaved them.
- **Tail dispatch.** `switch (t3) { case 0: case 1: ... }`. Written as

  merge. An if/else with an s16 local sign-extends first. A u16 local masks
  twice.
- **One-multiply.** The motion length is divided by
  `speed * (rate / 100.0f)` with `speed = 1.0f` set just before the call.
  Written as a literal `1.0f *`, b210 folds the multiply away. Retail keeps
  `mul.s` by one, so the value arrives through a variable.

  entries. This loads the base before the index and gives `addu idx, base`.
  The cast-at-use form ties at 7 words.
