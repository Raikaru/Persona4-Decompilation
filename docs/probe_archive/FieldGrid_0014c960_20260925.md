## Shape

The function walks the 24x16 grid from the saved cursor
(`iGpffffb1fc`/`iGpffffb1f8`). A cell qualifies when:

- its map cell (16 bytes at `func_00155280() + y*0x100 + x*0x10`) is type 1;
- its kind is 9, 11 or 13;
- its high nibble is 2;
- its bit in the u16 row mask is clear.

The 2x2 block must then be clear of three kinds of occupant: 8 entities in
`D_007E80A0` (0x168 stride), the `func_001452b0(3)` object list, and 15
entries in `D_007E8C00` (0x750 stride). Each occupant is placed on the grid
at `(s32)((600 + pos) / 1200)`. A hit marks the 2x2 block and moves on to
the next x. On success the function stores x and y, marks the block, saves
the cursor and returns 1.

## Levers

- **Each scan is its own block with its own `clear` flag.** Retail keeps
  them in different places: the first in `$v0`, reusing the `1` from the
  test; the second in `$s6`, because it lives across the list walk's calls;
  the third in `$t2`. One shared flag costs 40 edits.
- **The hit test is an expression macro inside the `if`**
  (`FLD_GRID_HITS`). An inline function returning the `||` chain turns
  into `xor`/`sltiu` flag arithmetic and loads the second coordinate first.
- **`D_007D24B0` is `u16[]`.** It was declared `u8[]`, and this file is its
  only user. `D_007D24B0[y + 1]` then folds to the symbol+2 base
  (`lui`/`addiu D+2; addu y*2`) that retail uses in the final mark.
- **The mark's bits are `(u16)(1U << x)`.** The signed spelling is CSE'd
  with the occupancy test's `1 << x` into a saved register, which pushes
  `arg1` to the stack (106 -> 45 edits). Writing the ORs directly, without
  `u16` temporaries, schedules the final mark as retail does (11 -> 0).
- **`#pragma opt_loop_invariants on`** (push/pop) hoists 600.0f/1200.0f,
  x+1/y+1, the table bases and the 0x750 stride that feeds `mult`.
