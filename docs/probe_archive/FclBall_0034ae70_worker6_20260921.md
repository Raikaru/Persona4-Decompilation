## Remaining differences and bounded families

The first two constructor calls load alpha before setting up the aggregate output
and RGB arguments. Retail loads alpha after them. The third, half-alpha constructor
already has the observed argument sequence.

The explicit depth pointer becomes `lui` plus `addiu` in one register, while retail
keeps the high address in another register and uses the low relocation directly in
`lwc1`. This also changes the loop counter's register. Direct global access removes
the separate address instruction but either moves the depth value outside the loop
or rematerializes the address inside it, depending on the tested optimization
scope; the resulting loop register changes are broader.
