## Shape

The function runs one loop or block per layout (0xB5 = 6, 8, 5, 7, 9). Each
slot either:

- slides in: two `func_002b2970` positions, `func_00317900`, and two s16
  stores to `p + index * 10 + 0xCA`; or
- is thrown out: a `RpRandom() % 300 - 150` jitter and the same three calls.

Retail keeps 70 eight-byte positions on a 0x2E0 frame, in descending order of
use. A caller-side `FclPackedPosition pos[70]` reproduces that layout.
Positions local to an inline helper got 16-byte slots (frame 0x4B0).

## What paid off

- Rewriting from the retail assembly under `opt_loop_invariants on`,
  `opt_propagation off` and `opt_lifetimes on`: 579 edits.
- Dropping `opt_loop_invariants`, together with the per-case mode below.
  That pragma hoisted the -200/-300/100 float constants and -150 out of the
  loops, which retail does not do.
- Per-case mode: `for (i1 = 0, mode1 = (s8)arg1; ...)` with an `s32 mode1`.
  Retail extends `arg1` once, after the counter is zeroed, and then tests the
  register directly (579 -> 348 in the 0xB5 == 6 loop).
- `idx = (s16)(i1 + 0)` at the top of the slide-in branch. Retail
  re-extends the counter into a saved register there instead of reusing the
  loop-test value (348 -> 346).

## Blockers

- **Applying the per-case mode to the other four layouts gets worse**
  (841 edits). The object then stops using `$fp` and the frame shrinks to
  0x2D0, which shifts every position slot by 0x10. Retail needs one more
  saved register than that allocation uses. `$fp` holds the re-extended
  index in the 0xB5 == 9 right-hand throw branch, computed after `RpRandom`.
- **Register allocation**: `p`/`i`/`arg1` land in s2/s3/s4 against retail's
  s3/s2/s7.
- **The 700.0f constant**: retail keeps it in `$f20` after the first
  right-hand block and loads it in both branches of that block.
- **Throw-branch index**: in the 0xB5 == 9 right-hand throw branch, retail
  re-extends the index only after the jitter call.
- **Inline helpers** (slide-in and throw-out, taking the caller's position
  slots) reproduced the per-block registers. But their index binding sinks
  to the first use instead of the branch top (833 edits), and the frame
  lost `$fp`.
