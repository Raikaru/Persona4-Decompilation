## Key lever: the 1/255 scale is a float literal, not a global

`gp-0x7FBC` (0x00761134, recorded as `iGpffff8044`/`fGpffff8044`) is shared by
many units (effBlurFilter etc.): it is a merged `.sdata` literal. Writing
`(f32)(u32)c * (1.0f / 255.0f)` emits the gp-relative literal load. With the
literal, the unit's normal CSE setting reproduces retail exactly:

- the literal is reloaded per channel (each channel's u32->f32 conversion is its
  own diamond, so the literal load sits in a separate basic block), and
- the compiler-generated `0.0f` accumulator seed of the four `adda.s/madd.s`
  quantisers is shared in one register.

Both earlier floors came from forcing reloads of an extern global with
`opt_common_subs off` (00476e90: 73 words; 00479100: 29 words) - CSE off is what
re-materialised `mtc1 $zero` three times. Both pragmas are now gone.
