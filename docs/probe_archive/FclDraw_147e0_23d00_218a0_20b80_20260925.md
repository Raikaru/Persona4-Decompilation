## func_003147e0: MATCH (was 16 words)

Closed by re-deriving which variables own the loop registers, not by
permuting names. Retail's loop counter sits in the register of the early
resource id (`$s0`), and the row resource sits in a web of the multiply
assigned `base` local, so the loop is
`for (id = 0, o2 = order + 4; id < 2; id++) { r = id + 0x174; base = r;
func_002b77d0(base, ..., r, ...); }`. Declaration order has no effect here
(60 random orders all tie). A fresh counter or resource local either rotates
the registers or is propagated away (562 words). Staging `o2 = order + 4` as

the init order (19 words). Dropping the colour locals that are assigned
inside the 77d0 arguments costs 8 words, and dropping `opt_loop_invariants`
costs 601. The history below is the pre-match state.
