## Reusable levers

- b210 keeps a dead loop counter when the same C variable is also live in
  a later loop (func_0015e960). With block-scoped counters it is deleted.
- Retail sequences like `sltu x, $0, live; li 1; bne` come from
  `(u8)(live != 0) == 1`. Plain `(live != 0) == 1` folds to beqz.
- Struct-array accesses written as byte offsets
  (`(T *)((u8 *)base + i * sizeof(T))`) give retail's `addu base, off`.
  Array indexing gives `addu off, base` (func_0015f000).
- Caller-side coalesced copies (`else if (arg1 != NULL) fbn = arg1; else
  return 1;`) reproduce retail's `beqz; b` pairs.
- A fast scorer that skips fndiff's whole-tree marker scan (about 0.3 s per
  compile) makes declaration-order hill-climbs practical. Callee-saved
  ranking was usually last-declared-highest in these targets, but block
  locals and CSE temporaries do not follow it.
