entry count is at most `D_00748908[list]`, it runs the first slide's
`func_002b2aa0`/`func_002b2cb0` step. It then recolors the three header bars
(the `0xE68` set when `list == work[0x11]`, otherwise the `0xF08` set) and

`2b2aa0`/`2b2cb0`) and moves the cursor marks to the scrolled row. If the row
is valid it draws either the three header frames (list 0, row 0, at least two
entries) or one of eleven category icons, the name (`func_00275680`), and two
number fields (`func_002cacd0`).
