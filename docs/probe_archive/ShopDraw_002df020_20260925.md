# Shop detail panel 002df020

`func_002df020` now matches: 1,180 native bytes in the 1,184-byte retail
window (296 words); the last word is zero alignment. All 51 code
relocations (32 calls, 9 HI16/LO16 pairs, 1 GPREL16) resolve, including the new gp-relative `uGpffffa888`
(`ld -0x5778($gp)`, recovered at `0x00763978` by `tools/recover_symbols.py`).
The previous floor was 219 differing words
(`ShopDraw_002df020_body.c`); every other function in

## What closed it

1. **Switch, cases written 0, 1, 2.** The retail dispatch `beq 2 / beq 1 /
   beqz 0 / b join` with bodies laid out 0, 1, 2 is a `switch` (b210 tests
   the last-written case first). The old `goto` chain lost two words to the
   "branch around goto" fold and shifted everything after it.
2. **Colours as values.** `fclWriteColorBytes` copied the four bytes into a
   second slot. Passing `func_002b2a60(...)` directly as the `FclDrawColor`
   argument of `func_002cacd0` keeps retail's single `0xBC/0xB8/0xB4` slot.
   The alpha argument `lbu 0x62($v0)` sits in argument-slot order (after the
   constants) only when the packer's parameters are `u8`; with `s32`
   parameters b210 hoists the load as a conversion. `fcl_color.h` now lets a
   unit choose the parameter type (`FCL_COLOR_ARG`); this unit uses `u8`,
   every other unit keeps `s32` (their retail call sites pass `int` values
   unmasked).
3. **Struct-return position constructor.** With
   `Vec2f func_002b2970(f32, f32)` used directly as an argument, each
   position is a compiler temporary. That alone moves `work` to `$s1` above
   the call-result values in `$s0` (a temporary interfering with a
   base-only pointer flips b210's otherwise fixed colouring; declaration
   order, splitting and renaming locals were all measured inert) and lays
   the temporaries out below the named `pos` exactly as retail. The name
   line is an inline `shopDrawName(text, pos, color)`: b210 evaluates the
   inlined call's arguments right to left, which gives retail's colour /
   constructor + float copy into the parameter slot / name order.
4. **Prototype evidence.** `arg1` is `s32`: it reaches `func_00106880` and
   `func_001067f0` unextended (int parameters in this unit) and is
   sign-extended only for `func_00106a90` (`s16`). `func_002cacd0` now takes
   `(Vec2f, f32, FclDrawColor, ...)`; its own body is unchanged in bytes.

## Unit-wide consequences

The file-scope prototype change converts 168 matched call sites to
`x = func_002b2970(a, b)` (identical bytes; `u64` position locals became
`Vec2f`, read back as `*(u64 *)&x` where `func_002e0620` takes a packet).
An `FclPackedPosition` union for those locals was measured and breaks seven
functions, so it was not used. Guarded `NON_MATCHING` bodies were rewritten
to `*(Vec2f *)(p) = func_002b2970(a, b)` and cast arguments for
`func_002cacd0` so that `measure_guarded.py` still compiles them; their
stored floor numbers predate this change.
