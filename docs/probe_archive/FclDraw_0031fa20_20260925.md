# Glow rows: exact `func_0031fa20`

`func_0031fa20` in `src/Event/Fcl/y_fclCombineDraw.c` is now exact over its
full 3024-byte window, with every relocation resolved. It starts from the
struct-return draft `FclDraw_0031fa20_body.c` (555 words) and needed three
more levers.

1. **Make the homed anchor addressable.** One read is spelled
   `*(f32 *)&arg1` (the first `func_002b6c30` x). The other reads stay as
   `arg1.x` / `arg1.y`.
   - **Effect.** b210 then treats the `sd $a1, 0x58($sp)` home as memory
     that calls can clobber. So `y = arg1.y` is loaded after
     `func_0046d200` rather than hoisted to entry, and each block reloads
     sp58/sp5C. This also removes the third saved FPR.
   - **Spellings that failed.** Plain field access, `(&arg1)->x`, `(void)&arg1`
     and an unused pointer local do not mark the home addressable.
   - **Spellings that leave a base register.** Using the cast for the y half,
     or a real `FclVec2 *p = &arg1`, CSEs `sp+0x5C` into `$s1`.
2. **Offset rows load `arg1.y` first.** They read `top = arg1.y;` and then
   `y = 4.0f + top;` (or `9.0f`). Retail loads the half before it
   materialises the constant, and has the extra `nop`.
   - Writing `y = 4.0f + arg1.y` directly schedules the constant first.
   - Reusing `y` itself (`y = arg1.y; y = 4.0f + y;`) flips the `add.s`
     operands.
3. **One node handle per block** (`node0`..`node3`, with the last two rows
   sharing `node3`). A single reused handle coloured arg2/arg3/handle as
   `$s2/$s0/$s1`, against retail's `$s0/$s1/$s2`. Declaration order,
   parameter widths and local copies of arg2/arg3 did not move it.

Signature: `(u8 *, FclVec2, s32, s8)`. It has a local
`func_002b69f0(s16, FclVec2, FclVec2, u32, u32, s32)` so arg2 is passed
raw. Block 1 keeps `x = arg1.y`: renaming it to `y` costs 22 words of FPR
colouring.

The sibling `func_0031e5b0` has the same shape (per-block handles, packed
anchor) and may take the same levers.
