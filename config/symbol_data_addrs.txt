// Curated data addresses that tools/recover_symbols.py cannot derive.

// That tool infers addresses from relocations in MATCHED functions. Two cases
// escape it: a symbol whose only references are still INCLUDE_ASM (no relocation
// to learn from), and a symbol whose NAME disagrees with its true address, which
// the cross-file consistency check drops as a conflict.
//
// Dropping either is silent -- the per-function verifier masks relocations, so
// the build still reproduces both retail hashes and only the count of linked C
// objects falls. Every entry below therefore carries an `evidence:` note stating
// how the address was established, and tests/test_recovered_symbols.py re-checks
// the checkable ones against the retail image.
//
