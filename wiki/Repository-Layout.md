# Repository Layout

```text
src/                        C units and INCLUDE_ASM fallbacks, one file per translation unit
  Battle/ Camp/ Event/ ...  Atlus code, grouped by original directory where known
  *.c                       units with a known file name but no known directory
  promoted/code1_XXXX.c     units named by address until the original file is identified
  renderware/               RenderWare Graphics 3.7, ported verbatim (build 119)
  rw/                       other RenderWare functions, grouped by attributed source file
  cri/                      CRI ADX/Sofdec; libadxe/ and re4/ hold two upstream reconstructions
  sce/                      Sony SDK units
  middleware/               GCC runtime and other ee-gcc vendor units
  generated/                m2c candidates (M2C_CANDIDATE); not verified, linted or linked
include/                    type.h, include_asm.h, project headers
  rw/                       RenderWare headers (see RenderWare)
  cri/                      CRI headers
asm/                        macro.inc and a few hand-maintained fallbacks; the split output is ignored
config/
  target.json               executable identity: disc and ELF hashes, entry, gp, segments, compiler evidence
  slus21782.yaml            splat configuration
  generated_asm.json        manifest and hashes for make regenerate-asm
  compiler_units.txt        unit -> non-default compiler key
  version_flags.txt         compiler key -> extra flags and include roots
  speed_units.txt           units compiled with ,p
  gcc_units.txt             units compiled with ee-gcc 2.96
  link_floor.json           minimum number of source units in the link
  symbol_data_addrs.txt     curated data symbols, each with its evidence
  symbols_recovered.txt     generated by tools/recover_symbols.py; read by the build
  symbol_names*.txt         function names by source (curated, P3, strings, vendor)
  symbol_addrs.txt          generated by make reconcile; splat's symbol list
  sdk_symbol_provenance.txt archive-backed Sony SDK identifications
tools/                      build, verification, lint and analysis (see Tools)
  slus21782_functions.json  canonical function windows
tests/                      tooling tests (make test)
wiki/                       these guides
docs/
  STYLE.md                  naming, typing and source-honesty rules
  matching.md               measured source shapes and compiler behaviour
  compiler-floors.md        measured compiler limits, and shapes that turned out not to be
  gnu_linker.md             the GNU ld backend
  probe_archive/            earlier attempts at unmatched functions, with measurements
  cri/ sky2/                naming and attribution evidence for CRI and the RenderWare driver
  ida_headstart/ ghidra_headstart/
                            decompiler drafts for unmatched functions
progress/                   committed progress endpoints (make progress)
.github/workflows/          CI; the full build job needs a private dependency repository
Dockerfile                  build environment without the proprietary files
```

Ignored local files: `orig/`, `image.bin`, `build/`, `assets/`, the split
output under `asm/`, and `tools/*_config.local.json`. `make clean` removes
`build/`, `assets/`, `asm/data/` and the top-level `asm/*.s`; the per-function
fallbacks stay. `make distclean` also removes `orig/` and `image.bin`.

The other files under `docs/` are dated research notes and handoffs. They
record what was known when they were written.

## Ownership

Each function window in `tools/slus21782_functions.json` belongs to one
`// FUN_XXXXXXXX` marker in one file under `src/` (outside `src/generated/`).
The marker is followed by matching C, an `INCLUDE_ASM` line, or a
`#ifdef NON_MATCHING` attempt with its fallback. See
[How Matching Works](How-Matching-Works).

## Unit names

Atlus's build left `__FILE__` strings in assertions, so many units carry
their original names (`btlUnit.c`, `k_fldEvent.c`, ...). `make file-strings`
recovers them. Code the strings do not cover stays in
`src/promoted/code1_XXXX.c`, named by address. Rename a unit once it is
identified, but do not split or merge units without evidence: unit
boundaries change the generated code and the link layout.
